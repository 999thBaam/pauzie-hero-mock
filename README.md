# Pauzie hero mock

Three strips of real-life scenes (everyone hooked on phones) scroll sideways around the Pauzie device. Scroll: device turns, strips slow, one tap stops them, every scene flips to its phone-free version from the device outward.

- Device: Pact v1 model (Draco GLB), three.js r160.
- Scenes: OpenAI gpt-image-2 (`gen/gen.py`). Day pictures are edits of the night pictures, so people and rooms stay the same.
- `?p=0.4` freezes a frame (0..1).
